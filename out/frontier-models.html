Frontier models — capability vs cost and size

Every number on this page comes from artificialanalysis.ai and nowhere else — the model leaderboard and the Coding Agent Index. The first three charts pair an AA capability index with AA's measured cost to complete one task in that same index, so they share an axis and read against each other; the fourth swaps that axis for AA's reported total parameter count and so sits apart, last. Together they show both economic and parameter efficiency without stitching numbers from different sources.

Cost per task is measured, not quoted. It is what Artificial Analysis actually spent running the model through each index — input, cached reads, output and reasoning tokens included — so a verbose reasoning model costs more than its per-token price suggests. That is also why the plot is smaller than the full catalogue: AA lists — models, while complete score-and-cost pairs cover — agent runs for Coding, — models for Intelligence and — for GDPval-AA; — models have both Intelligence Index and total parameters. Everything else is absent rather than estimated.
Two chips do the real work. Hide superseded drops every model that another model beats on both axes at once — the metric's verdict, not the vendor's retirement flag, and recomputed against whatever else you have filtered to. Dump effort levels collapses each model's effort settings to a single row at its highest score for each chart, applied before that chart's superseded test so every frontier is drawn between models rather than knobs. Because a configuration can peak on one capability but not another, all four charts collapse and judge dominance independently.
