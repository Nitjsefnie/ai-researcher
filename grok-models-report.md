# xAI Grok Model Lineage — Complete Reference (May 2026)

Compiled chronologically. Per-model template per coordinator schema: typed
`Sources:` blocks (`announcement` / `model-card` / `pricing` / `deprecation` /
`coverage` / `replication`), and benchmark rows surface both `lab` and `3p`
numbers where they disagree by >3 pp.

**Methodology caveats.** xAI's primary blog (`x.ai/news/*`) and pricing page
(`x.ai/api`) return HTTP 403 to non-browser fetchers, so many `lab`-tagged
benchmark numbers in this report are routed via 3p coverage that quotes the
original blog post (`grokipedia.com`, the-decoder, datastudios, mindstudio,
felloai, Wikipedia) or via aggregators (Artificial Analysis, llm-stats,
PricePerToken, OpenRouter, Vals.ai). Where xAI ships a model card PDF
(`data.x.ai/...pdf`) we treat that as canonical. Where pricing has drifted
across the Grok-3 → Grok-4 → Grok-4.3 transitions (xAI cut prices on each
generation), the historical sticker price is recorded at the row and the
*current* price is noted in the row only if the SKU still exists.

**"Heavy" semantics.** "Heavy" is consistently a **consumer subscription tier**
on X / SuperGrok ($300/mo SuperGrok Heavy), not a separate API SKU. The
subscription tier runs multi-agent inference on the same underlying weights.
The closest API analogue, when one exists, is the `grok-4.20-multi-agent-0309`
SKU (Grok-4.20 generation only). For Grok-3 Heavy and Grok-4 Heavy there is no
named API SKU; those numbers were generated by the consumer tier.

Convention: dates are **announcement / first availability**; broad rollout (X
free tier etc.) is noted in `Notable` when material.

### Grok-1

- Release: 2023-11-04 (announcement); 2023-11-05 first availability to X Premium+
- Status: legacy (superseded; open-weight checkpoint remains downloadable)
- Decommissioned: never had a paid API SKU; chatbot tier replaced by Grok-1.5 in Mar 2024
- Context: 8,192 tokens
- Modality: text only (English)
- Price (in/out per 1M): not offered on a public API
- Notable: 314B-parameter Mixture-of-Experts (8 experts, ~25% of weights active per token); open-weighted under Apache 2.0 on 2024-03-17; first-ever frontier-tier model published with weights fully open at this scale.
